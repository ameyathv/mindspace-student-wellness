MINDSPACE — STUDENT WELLNESS BLOG PROJECT

Included:
- index.html: complete responsive website with HTML, CSS, and JavaScript
- This README with beginner setup instructions

PREVIEW ON WINDOWS
1. Extract the ZIP file.
2. Double-click index.html to open it in Chrome.
3. Test the blog article links, gentle pause interaction, daily check-in, and demo form.
4. Replace the footer placeholder in index.html with your name/class before publishing.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign into GitHub.
2. Create a PUBLIC repository named mindspace-student-wellness.
3. Click Add file -> Upload files.
4. Upload index.html (not only the ZIP) and commit changes.
5. Open repository Settings -> Pages.
6. Under Build and deployment choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait for the published URL shown on the Pages screen. Test it in a new tab.

GOOGLE ANALYTICS
1. Open analytics.google.com and create an account/property.
2. Create a Web data stream using the actual published URL.
3. Copy the Google tag / measurement ID (starts with G-).
4. Follow the current Analytics instructions to add the full Google tag inside the <head> section of index.html.
5. Upload/commit the updated index.html to GitHub.
6. Open the live site and test Reports -> Realtime. It may take time to collect data.
7. Use actual data only; do not invent visitor numbers.

GOOGLE ADS PREVIEW
1. Open ads.google.com and sign in.
2. Follow your teacher's requirements to prepare an ad draft for the published MindSpace URL.
3. Use the ad preview available in your account/setup flow.
4. Stop before enabling/launching a paid campaign. If billing or activation is requested, pause and confirm with your teacher. Ads account requirements and interface may vary.
